# TrehonStudioFit
Sistema web de gestão para academia

## Objetivos
Desenvolver uma aplicação que permita os instrutores:

-cadastrar alunos;
-cadastrar exercícios;
-criar fichas de treino;
-gerenciar mensalidades;

Os alunos poderão:
-visualizar sua ficha de treino;
-registrar desempenho ao longo do tempo;
-visualizar histórico do desempenho;

## Tecnologias planejadas

-React
-TypeScript
-Supabese
-PostgreSQL
-CloudFlare Pages
